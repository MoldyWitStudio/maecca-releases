# Maecca

Download the Maecca desktop app for Windows, Mac and Linux: **https://maecca.com/download**

This repository only holds the published app files. The app checks `latest.json` here for updates;
it is signed (`latest.json.sig`), and every file is checked against its SHA-256 before it is installed.

Version 0.1.0 (build 6).
